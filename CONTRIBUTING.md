# Contributing to dsh-provider-config

Thanks for your interest in contributing!

## What We Accept

- 新的供应商配置模板（脱敏，不含真实 key）
- 重试机制 / 限流排查的改进文档
- 配置模板的 bug 修复

## How to Contribute

1. **Fork** the repository and create a branch
2. **Make your changes** — keep them focused
3. **Never include real API keys** — only environment variable names
4. **Submit a pull request** with a clear description

## Security

If you find a security issue, follow [SECURITY.md](SECURITY.md) — do not open a public issue for it.
