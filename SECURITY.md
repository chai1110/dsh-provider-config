# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately to chai011379@gmail.com.

**Never include real API keys or credentials in issues, pull requests, or any public channel.**

We will acknowledge receipt within 48 hours and work on a fix as quickly as possible.

## What This Project Contains

This project contains **configuration templates only** — no real API keys, no credentials, no secrets. All keys are referenced via environment variable names (e.g. `SENSENOVA_API_KEY`). If you see a real key in this repository, that is a security issue — report it immediately.
